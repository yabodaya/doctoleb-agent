# VS-008: Voice notes in
Status: IN PROGRESS

## Goal
Voice note -> transcript -> same Agent Core -> text reply.

## Scope
- Handle audio messages: get media URL by media id, download (auth header), size/type checks
- Store audio in object storage (local MinIO in compose) with retention setting
- Transcribe via OpenAI audio model; store transcript on message; modality=VOICE_NOTE
- Unclear/empty transcript -> ask patient to repeat or type

## Acceptance
- Arabic and English voice notes get correct replies
- No transcript text in logs

## Understand first
Media download flow in Cloud API (media id -> temporary URL -> bytes).
