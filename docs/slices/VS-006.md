# VS-006: Agent Core + first tool
Status: IN PROGRESS

## Goal
"Is Dr. Karim available tomorrow afternoon?" -> AI calls search_available_slots -> real answer.

## Scope
- BookingClient protocol + FakeBookingClient (seeded doctors, services, slots)
- Tool framework: tool registry, Pydantic arg validation, tool execution logging (agent_runs, tool_executions tables)
- Tools: get_clinic_information, list_doctors, search_available_slots
- Tool-calling loop with a max-iterations limit
- Date handling: "tomorrow afternoon" resolved against Asia/Beirut time given in the prompt

## Acceptance
- The Dr. Karim flow works on WhatsApp with fake data
- Invalid tool args from the model are rejected and the model is told why
- Tests: tool loop terminates; tenant_id never appears in tool schemas

## Understand first
Tool/function calling: the model REQUESTS, our code EXECUTES and decides.
