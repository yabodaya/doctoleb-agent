# VS-010: Human handoff
Status: TODO

## Goal
AI hands over cleanly, and stays silent while a human is active.

## Scope
- Tool: request_human_handoff(reason) -> state HUMAN_REQUESTED, patient told a human will reply
- Auto-handoff triggers: medical/symptom questions, urgency, repeated confusion, explicit request
- Internal API for dashboard: take over (HUMAN_ACTIVE), send staff message, release to AI, close
- Staff auth: TBD with dashboard owner

## Acceptance
- "I want to talk to a person" -> handoff; subsequent patient messages get no AI reply until released
- Race test: takeover during AI processing -> AI reply dropped

## Understand first
State machines; race conditions and why we re-check right before sending.
