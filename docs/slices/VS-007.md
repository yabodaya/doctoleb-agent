# VS-007: Booking tools
Status: IN PROGRESS

## Goal
Patient can hold, book, reschedule and cancel through conversation, safely.

## Scope
- Tools: hold_appointment_slot, book_appointment, reschedule_appointment, cancel_appointment, list_my_appointments
- FakeBookingClient simulates SLOT_TAKEN, HOLD_EXPIRED, errors
- Idempotency-Key derived from source message id
- Prompt + code guard: confirmation text only after success result (hard rule 5)
- Always confirm details (doctor, date/time, name) with the patient before book_appointment

## Acceptance
- Full booking flow on WhatsApp against fake service
- Tests: SLOT_TAKEN -> AI offers alternatives, never says "confirmed"; duplicate job -> one booking call effect

## Understand first
Idempotency keys; holds vs bookings; why the model can't be trusted to judge success.
