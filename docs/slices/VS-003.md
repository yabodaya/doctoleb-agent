# VS-003: Receive WhatsApp webhook
Status: TODO

## Goal
Real WhatsApp message from my phone is verified, deduplicated and stored exactly once.

## Scope
- `GET /webhooks/whatsapp`: Meta verification handshake (hub.mode, hub.verify_token, hub.challenge)
- `POST /webhooks/whatsapp`: verify X-Hub-Signature-256 against raw body, reject invalid (401)
- Pydantic models for the payload (messages + statuses), tolerant of unknown fields
- Insert into webhook_inbox; duplicate -> still return 200, do nothing
- Local public URL via cloudflared or ngrok (document in README)

## Out of scope
Processing, replying, AI.

## Acceptance
- Meta dashboard webhook verification succeeds
- Message from my phone appears in webhook_inbox
- Tests: bad signature -> 401; same payload twice -> one row; status events handled without error

## Understand first
What a webhook is, why signature verification uses the RAW body, why Meta retries.
